Varnish and 2.5D relief: building height on purpose

Varnish is a build material, not just a shine. Spot varnish adds contrast; multiple passes add real height. The hard part is curing the middle of the stack and keeping dust out of a wet, glossy surface.

  • varnish
  • spot UV
  • 2.5D relief
  • gloss

The short answer: varnish is printed like an ink, so it can be stacked. One pass gives gloss and a little protection; three or four passes on a spot channel give a raised, tactile relief that catches the light. The skill is not in the file — it is in curing each layer enough to hold the next one, without overcuring the surface into a brittle shell.

Spot varnish is usually the better choice

Full-flood varnish makes the whole sheet glossy, but it also shows every speck of dust and every slight height difference. In our experience spot varnish — gloss on the logo or the pattern only, matte or bare ink elsewhere — reads as more expensive and is far more forgiving in a normal workshop. Full flood belongs in a clean room or behind a laminator, not next to a loading dock.

How the height is built

  1. Make a spot channel in the design file for the areas that get varnish; keep the edges hard.
  2. Set the number of passes (or the ink limit) in the RIP, not in the image.
  3. Print and pin-cure each varnish pass so it holds shape but still bonds to the next.
  4. Finish with a full cure pass; check with a thumbnail twist after the part cools.
  5. If the relief needs to survive handling, add a protective top coat or choose a harder varnish.

Field note

Workshop note: the classic 3D relief recipe in the trade is not magic — make a spot channel, then raise the white/varnish pass count in the RIP. What the recipe does not tell you is that a heavy white under a heavy varnish cures from both sides unevenly. We build in thinner layers and give each one a real cure, even if it costs a pass.

One more trade-off: gloss is not abrasion resistance. A high-gloss varnish can look beautiful and still scuff in a bag. If the part will be handled, ask for a harder varnish or a protective top layer, and test it the way it will be used.

If a client asks for 'a thick gloss', agree on a target in the quote: a single pass reads as gloss, a two-to-four-pass build reads as relief. A small sample next to the price prevents most of the arguments about what 'thick' means.
