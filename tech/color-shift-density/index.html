When the colour drifts: check the machine before the ICC

A colour shift after months of good output is usually a physical change — ink lot, head condition, lamp output, temperature or media — not a broken profile. Measure density first; re-profile last.

  • colour drift
  • density
  • ICC
  • lamp decay
  • ink lot

The short answer: if a job that used to match now prints greenish, the profile is the last thing to suspect. Ink, head, lamp and temperature all drift slowly, and each of them changes density before it changes hue. Measure a known patch, compare it with the last good job, and work backwards through the ink path.

Ink and consumables

  • Different ink lots can differ slightly in pigment load; record the lot on every job.
  • Expired or badly stored ink changes colour and viscosity; keep stock cool and sealed.
  • Mixing brands or grades without flushing leaves a blend in the damper that no profile can correct.
  • White ink that has settled prints weaker, which shifts every colour printed on top of it.

When it really is the profile

If density is stable, the nozzle check is clean, the lamp is within its service window and the media lot has not changed, then look at the RIP: a corrupted profile, a colour-managed application updating itself, or an accidental switch of rendering intent. Our 2022 note on colour drift mentions ICC corruption from a computer virus — rare, but it happens, and it is why we keep a known-good profile and a printed reference patch.

Field note

Workshop note: we keep a physical reference print — a small sheet with grey steps, a skin tone and a saturated red — from the day the profile was verified. When a customer says 'this looks different', the sheet settles it in a minute: if the reference reprints correctly, the file or the media changed; if it does not, the machine changed. Cheaper than re-profiling on suspicion.

Re-profiling is the correct last step, not the first. A new ICC printed over a failing head or a tired lamp will match today and drift again next month, and you will have spent the time twice.

And remember that the same file can change with a RIP upgrade or a different rendering intent. After any software update, print the reference sheet before taking a paying job.
